## 📝 Design Best Practices

### Visual Hierarchy
- Use size, color, and spacing to guide the eye
- Most important elements (CTAs) should be largest and most prominent
- Consistent spacing system (8px grid)

### Color Psychology
- Green/Emerald: Growth, wellness, health
- Blue: Trust, calm, medical
- Purple: Creativity, mindfulness
- Use high-contrast CTAs

### Typography
- Clear font hierarchy (h1 > h2 > h3 > body)
- Readable font sizes (min 16px for body)
- Limited font families (2-3 max)

### White Space
- Generous padding around sections
- Breathing room between elements
- Not cluttered or overwhelming

### Consistency
- Button styles consistent throughout
- Card designs match across features
- Icon style consistent
- Animation timing consistent
