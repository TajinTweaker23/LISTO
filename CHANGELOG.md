# Changelog

All notable changes to the LISTO app will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

### Security
- Documented security vulnerabilities and remediation plans
- Added GDPR/HIPAA compliance requirements

## [1.0.0] - TBD

### Added
- Neurodivergent-friendly wellness dashboard
- Energy tracking with personalized recommendations
- Mood tracker with emoji-based interface
- Anonymous social features (Resonance Circles)
- Vision board with moodboard presets
- PWA support for offline functionality
- Multi-platform support (iPhone, iPad, desktop)
- Mexican culture-inspired branding and logo
- Glassmorphism UI design
- Dark mode support
- Focus mode for neurodivergent users
- Health tracking integration
- Google Maps and Leaflet integration
- AI-powered insights (Genkit, Vertex AI)

### Security
- Rate limiting implemented
- XSS protection enabled
- CSRF protection enabled
- Firestore security rules configured
- Source code obfuscation in production builds

### Technical
- Built with Next.js 15.5.6
- React 18.3.1 with TypeScript 5.3.3
- Tailwind CSS 4.1.7 for styling
- Firebase backend (Firestore, Functions, Auth)
- Framer Motion for animations
- Jest testing framework
- GitHub Actions CI/CD pipeline

### Migration Guide
No migration steps required for initial release.
